LiveCut 是一款面向 iPhone 用户的轻量视频截取工具。它解决的核心问题很直接：用户已经拍下了一段视频，但真正想保存、分享或设置为动态壁纸的，往往只是其中短短几秒。LiveCut 让用户在一条可缩放时间轴上精确选取片段、指定关键封面，并保存为 Live Photo。

当前仓库版本为 **V0.1**，聚焦“本地选择、精确截取、封面确认、立即保存”这一条完整主流程。

## 产品定位

LiveCut 不是一款复杂的视频剪辑器。它专注于一个高频且边界清晰的任务：从已有视频中快速提取 1～5 秒的动态瞬间。

产品价值主要体现在三个方面：

- **降低制作门槛**：无需理解轨道、转场或导出参数，选中片段即可生成。
- **提高选帧精度**：支持双指缩放时间轴，在长视频里也能定位到更具体的画面。
- **保护内容隐私**：视频处理在设备本地完成，不上传到外部服务器。

## 典型使用场景

### 从长视频中保留高光瞬间

旅行、演出、运动或宠物视频通常包含大量过程画面。用户可以放大时间轴，快速找到表情、动作或构图最好的几秒，将其保存为更容易回看和分享的 Live Photo。

### 补救错过 Live Photo 的拍摄

用户拍摄时可能使用了普通视频模式，但事后发现其中某个瞬间很适合作为 Live Photo。LiveCut 可以直接使用已有素材，无需重新拍摄。

### 连续提取多个片段

同一段视频里可能存在多个值得保留的瞬间。每完成一个片段，LiveCut 会立即保存结果，并允许用户继续从当前视频选择下一段，减少重复导入素材的操作。

### 为相册和分享选择更好的封面

动态内容是否吸引人，首先取决于静态封面。LiveCut 提供独立的封面选择步骤，让用户在生成前确认最能代表这个瞬间的一帧。

## 适合谁使用

- 经常拍摄孩子、宠物、旅行和生活记录的普通用户。
- 希望从视频中制作动态素材的内容创作者和社交媒体运营人员。
- 需要快速整理活动、产品或品牌现场素材的市场同事。
- 不需要专业剪辑功能，只希望快速完成单一任务的用户。

## 使用方法

1. 打开 LiveCut，点击 **“从相册选择视频”**。
2. 在编辑页面拖动左右手柄，设置 Live Photo 的开始和结束位置。片段时长支持 1～5 秒。
3. 拖动选区中央，可以在不改变时长的情况下整体移动片段。
4. 对长视频使用双指缩放时间轴；放大后，拖动时间轴下方的视频浏览柄查看前后内容。只有当 Live 选区离开当前可见范围时，它才会吸附到最近边缘。
5. 点击 **“预览片段”**，通过播放指针确认节奏和画面。
6. 点击 **“下一步：选择封面”**，拖动白色关键帧指针选择静态封面。
7. 预览确认后点击 **“生成并保存”**。保存成功后，可以继续处理当前视频或重新选择素材。

## V0.1 功能范围

- 从系统相册单选视频。
- 视频格式、时长和基础可用性检查。
- 单时间轴片段编辑。
- 独立的开始、结束手柄和等长选区移动。
- 双指缩放与独立视频窗口浏览。
- 1～5 秒片段边界约束和真实帧吸附。
- 所选片段循环预览与播放位置指示。
- 关键封面选择和预览。
- Live Photo 生成及系统相册保存。
- 同一视频的连续片段处理与当前会话导出标记。
- 重复片段提醒、处理进度和错误恢复提示。

## 产品原则

- **任务单一**：围绕“视频转 Live Photo”设计，不叠加通用剪辑器功能。
- **即时反馈**：调整、预览、生成和保存都提供明确状态。
- **结果优先**：每完成一个片段立即保存，避免复杂的批处理队列。
- **本地优先**：素材不离开设备，降低用户对隐私和等待时间的顾虑。
- **边界透明**：编译成功或保存回调不等于所有机型都已完成系统级兼容验证。

## 隐私说明

LiveCut 的视频读取、片段处理和 Live Photo 生成均在用户设备本地完成。应用不会把用户的视频、照片或编辑记录上传到外部服务。应用仅在用户主动生成结果时请求向系统相册写入内容。

## 开发与运行

### 环境要求

- macOS 与 Xcode 26 或兼容版本
- iOS 17.0 或更高版本
- 一台已信任并开启开发者模式的 iPhone，用于最终 Live Photo 验证

### 本地运行

1. 使用 Xcode 打开 `LiveCut.xcodeproj`。
2. 选择 `LiveCut` scheme。
3. 在 Signing & Capabilities 中选择自己的开发团队。
4. 如有需要，将 Bundle Identifier 修改为团队内唯一值。
5. 选择模拟器或已连接的 iPhone，点击运行。

## 技术说明

LiveCut 使用 SwiftUI、AVFoundation 和 Photos 框架构建。媒体生成流程位于 `LiveCut/MediaPipeline.swift`，片段边界与移动规则位于 `LiveCut/Clip.swift`。

`Tests/ClipTests.swift` 覆盖片段边界、选区移动及浏览窗口吸附规则，可用于检查核心编辑逻辑。

## 当前验证边界

V0.1 已完成项目构建、模拟器主流程检查和连接设备安装。不同机型、HDR/VFR 视频、低帧率素材、不同封面位置，以及系统照片 App 对最终 Live Photo 的识别和长按播放效果，仍应按照真机测试矩阵持续验证。产品对外发布前，应以真实设备中的最终结果为验收依据。
